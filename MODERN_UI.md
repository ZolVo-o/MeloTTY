# 🎵 Termusic Modern UI Edition

## ✨ Обновленный современный интерфейс

### Новые темы оформления

Добавлено **6 современных тем** с градиентами и расширенной палитрой:

1. **Cyberpunk** (тема по умолчанию) - неоновые цвета, футуристичный стиль
2. **Synthwave** - ретро-вейв эстетика 80-х
3. **Modern Minimal** - чистый минималистичный дизайн
4. **Gruvbox Modern** - классика с современными акцентами
5. **Nord** - холодные скандинавские тона
6. **Dracula** - тёмная вампирская тема

### Ключевые улучшения UI/UX

#### 1. Header с табами
- Градиентный заголовок с названием приложения
- Современные табы с активной подсветкой
- Три режима: Browser, Playlist, Search

#### 2. Dashboard "Now Playing"
- Расширенная информация о треке
- Анимированные бары визуализатора
- Индикаторы режимов shuffle/repeat
- Позиция в плейлисте

#### 3. Progress Bar со спектром
- Визуализация аудио-спектра в реальном времени
- Градиентный прогресс-бар
- Точные временные метки

#### 4. Улучшенные панели
- **Browser Panel**: двойные рамки, градиентное выделение
- **Playlist Panel**: улучшенная прокрутка, цветные индикаторы
- Иконки для типов файлов и папок

#### 5. Enhanced Status Bar
- Визуальный ползунок громкости
- Цветные индикаторы режимов
- Компактные hotkey badges
- Разделители секций

#### 6. Search Mode
- Анимированный курсор
- Подсветка поискового запроса
- Цветные инструкции

### Технические улучшения

- **Градиенты**: использование gradient_start и gradient_end для акцентов
- **Расширенная палитра**: cyan, magenta, pink, fg_dim
- **Несколько уровней фона**: bg, bg_dark, bg_darker для глубины
- **Модификаторы стиля**: BOLD, DIM для лучшей читаемости
- **Unicode символы**: современные иконки и разделители

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| Tab | Переключение между панелями |
| Space | Play/Pause |
| n | Следующий трек |
| p | Предыдущий трек |
| / | Поиск |
| 0/1/5 | Установка громкости |
| f | Перемешивание |
| r | Цикл повторения |
| q | Выход |

### Конфигурация тем

Темы определяются в `src/ui/theme.rs`. Каждая тема включает:
- Основную палитру цветов
- Градиентные цвета для акцентов
- Несколько оттенков фона для глубины

Для смены темы измените `DEFAULT_THEME` в `src/ui/mod.rs`:
```rust
pub use theme::CYBERPUNK as DEFAULT_THEME;  // или SYNTHWAVE, MODERN_MINIMAL, etc.
```

- Поддержка True Color (24-bit)
