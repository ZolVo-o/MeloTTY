# Улучшения Termusic

## Новые функции

### Навигация
- **g/Home** - переход к началу списка в браузере
- **G/End** - переход к концу списка в браузере  
- **Home/End** - навигация по плейлисту

### Управление воспроизведением
- **f** - переключение режима перемешивания (shuffle)
- **r** - циклическое переключение режима повтора
- Умная перемотка: нажатие **p** restarts трек если прошло > 3 секунд

### Плейлист
- Улучшенный алгоритм shuffle - никогда не играет один и тот же трек дважды подряд
- При отключении shuffle плейлист автоматически сортируется
- Исправлено поведение previous в режиме repeat all

## Исправления багов

### Критические
- ✅ Удалена утечка памяти (Box::leak в playlist_panel.rs)
- ✅ Исправлена прокрутка списков
- ✅ Корректное выделение текущего элемента в браузере

### Логические
- ✅ Repeat all теперь работает для previous с начала плейлиста
- ✅ Volume control через presets (1/5/0) и пошагово (+/-)

## UI/UX улучшения

### Статус бар
- Контрастные индикаторы режимов (зелёный фон для активных)
- Динамическая иконка громкости (🔊/🔉/🔈/🔇)

### Плейлист панель
- Правильная прокрутка с учётом видимой области
- Индикатор текущего трека: ▶ (играет), ⏸ (пауза)

### Браузер
- Закладки для быстрого доступа к важным папкам
- Иконки для типов папок (🏠, 🎼, 📥, etc.)

## Производительность

### Сборка
- LTO оптимизации включены в release профиле
- codegen-units = 1 для лучшей оптимизации
- panic = "abort" для уменьшения размера бинарника

### Код
- BufReader для эффективного чтения файлов плейлиста
- Оптимизированная загрузка аудиофайлов из директорий

## Поддерживаемые форматы
mp3, wav, flac, ogg, aac, m4a, opus, wma, **ape**, **alac**

## Горячие клавиши

### Глобальные
- `q` - выход
- `Tab` - переключение между браузером и плейлистом
- `Space` - play/pause
- `n/p` - следующий/предыдущий трек
- `h` - справка
- `/` - поиск
- `+/-` - громкость шаг
- `0/1/5` - пресеты громкости (100%/10%/50%)
- `f` - shuffle
- `r` - repeat mode

### Браузер
- `j/k` или `↓/↑` - навигация
- `g/G` или `Home/End` - начало/конец списка
- `Enter/l/→` - войти в папку / играть трек
- `Backspace/←` - назад
- `a` - добавить в плейлист

### Плейлист
- `j/k` или `↓/↑` - навигация
- `Home/End` - начало/конец плейлиста
- `Enter` - играть выбранный трек
- `d` - удалить трек
- `c` - очистить плейлист
